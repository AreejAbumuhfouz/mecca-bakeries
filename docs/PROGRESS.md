## 0) تجهيز الجهاز (مرة واحدة)

```bash
# 1. الأدوات
brew install node@22 pnpm postgresql@16 redis
brew services start postgresql@16
brew services start redis

# 2. قاعدتا البيانات
createdb mecca_bakeries
createdb mecca_bakeries_test
# إذا كان PostgreSQL مثبتاً من موقع postgresql.org (يطلب كلمة سر):
#   psql -U postgres -h localhost -d postgres -c "create database mecca_bakeries;"
#   psql -U postgres -h localhost -d postgres -c "create database mecca_bakeries_test;"

# 3. المكتبات
cd mecca-bakeries
pnpm install

# 4. ملف الإعدادات
cp apps/api/.env.example apps/api/.env
openssl rand -hex 32      # للمفتاح JWT_ACCESS_SECRET
openssl rand -hex 16      # للمفتاح OTP_PEPPER
open -e apps/api/.env     # ضعي القيم وسطر DATABASE_URL (انظري الجدول بالأسفل)
cp apps/web/.env.example apps/web/.env.local

# 5. بناء الحزمة المشتركة + إنشاء الجداول + حساب المدير
pnpm run bootstrap

# 6. (اختياري) بيانات تجريبية للعرض والاختبار
pnpm run demo
```

**سطر `DATABASE_URL`:**

| نوع التثبيت                        | السطر                                                                         |
| ---------------------------------- | ----------------------------------------------------------------------------- |
| Homebrew (بدون كلمة سر)            | `postgresql://اسم_المستخدم@localhost:5432/mecca_bakeries` (الاسم من `whoami`) |
| postgresql.org (المستخدم postgres) | `postgresql://postgres:كلمة_السر@localhost:5432/mecca_bakeries`               |

بعد كل `git pull`: `pnpm install` ثم `pnpm run bootstrap` (آمن للتكرار).

### التشغيل اليومي

```bash
pnpm dev:api    # نافذة 1 → http://localhost:4000/api/health
pnpm dev:web    # نافذة 2 → http://localhost:3000
```

رمز الدخول يظهر في نافذة الـ API في سطر `[DEV MAIL]` (لا يُرسل إيميل أثناء التطوير).

### تشغيل تطبيق المطاعم

```bash
# مرة واحدة: ضعي IP جهاز الـ Mac (System Settings ← Wi-Fi ← Details) في apps/mobile/.env
cp apps/mobile/.env.example apps/mobile/.env

pnpm dev:mobile                       # امسحي الـ QR بتطبيق Expo Go (الآيفون والأندرويد على نفس الواي فاي)
pnpm --filter @mecca/mobile web       # أو افتحيه في المتصفح على http://localhost:8081 للتجربة السريعة
```

ادخلي بـ `restaurant@example.com` (حساب مطعم تجريبي) — الرمز في نافذة الـ API.
بعد أول فتح على الجوال أغلقي التطبيق وافتحيه مرة ثانية ليظهر بالكامل من اليمين لليسار.

| --------------------------------------------- | -------------------------------------------------------------------- |

**QA يدوي:**

- [ ] فتح `localhost:3000` بدون دخول يحوّل لصفحة الدخول

- [ ] رمز خاطئ يعطي رسالة بالعربي؛ بريد غير مسجّل لا يُرسل له رمز

**QA يدوي:**

- [ ] الأسماء التجارية ← «+ اسم تجاري جديد» ← ارفعي شعاراً ← يظهر في البطاقة

## المهام 6، 9، 15 — العقود ومحرك الائتمان ✅

**تم:**

- عقد لكل عميل: المدة، طريقة الدفع (آجل/نقدي)، سقف الائتمان، مدة السداد، سماحية التأخير، خصم عام، المرتجعات ونسبتها، تنبيه التجديد، ملاحظات

- عقد واحد ساري لكل عميل في نفس الفترة
- الحالات: ساري، قارب على الانتهاء، لم يبدأ، منتهي، موقوف، ملغى
- التجديد بنقرة: عقد جديد بنفس الشروط والأسعار من اليوم التالي
- مرفقات خاصة (PDF/صور) لا يفتحها إلا من يملك صلاحية العقود
- تنبيهات التجديد في الصفحة الرئيسية
- محرك الائتمان: بدون عقد، حالة العقد، ذمم متأخرة بعد السماحية، تجاوز السقف؛ النقدي بدون سقف

- [ ] عمود «بعد الخصم العام» = السعر الأساسي ناقص 5%
- [ ] «تعديل الشروط» ← غيّري السقف ← حفظ ← تتغير حالة الائتمان
- [ ] غيّري طريقة الدفع إلى نقدي ← يختفي السقف ومدة السداد
