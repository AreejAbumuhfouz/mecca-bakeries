# متابعة التنفيذ والاختبار اليدوي

يُحدَّث هذا الملف مع كل مهمة. لكل مهمة: ما تم، وما تبقى، وقائمة اختبار يدوي (QA) تنفذينها قبل دمج الـ PR.

آخر تحديث: 2 نوفمبر 2026 — بعد المهمة 12.

## 0) تجهيز الجهاز (مرة واحدة)

```bash
# 1. الأدوات
brew install node@22 pnpm postgresql@16 redis
brew services start postgresql@16
brew services start redis

# 2. قاعدتا البيانات
createdb mecca_bakeries
createdb mecca_bakeries_test

# 3. المكتبات
cd mecca-bakeries
pnpm install

# 4. ملف الإعدادات
cp apps/api/.env.example apps/api/.env
whoami                    # اسم المستخدم على الـ Mac
openssl rand -hex 32      # للمفتاح JWT_ACCESS_SECRET
openssl rand -hex 16      # للمفتاح OTP_PEPPER
open -e apps/api/.env     # ضعي القيم الثلاث في أماكنها
cp apps/web/.env.example apps/web/.env.local

# 5. بناء الحزمة المشتركة + إنشاء الجداول + حساب المدير
pnpm run bootstrap
```

بعد أي `git pull` فيه جداول جديدة: أعيدي `pnpm install` ثم `pnpm run bootstrap` (آمن للتكرار).

### التشغيل اليومي

```bash
pnpm dev:api    # نافذة 1 → http://localhost:4000/api/health
pnpm dev:web    # نافذة 2 → http://localhost:3000
```

رمز الدخول يظهر في نافذة الـ API (لا يُرسل إيميل أثناء التطوير).

### أخطاء شائعة

| الرسالة                                       | الحل                                                                     |
| --------------------------------------------- | ------------------------------------------------------------------------ |
| `.env: not found`                             | الخطوة 4 لم تُنفذ                                                        |
| `password authentication failed for user ...` | `DATABASE_URL` فيها اسم خاطئ؛ ضعي ناتج `whoami` مكان `YOUR_MAC_USERNAME` |
| `role "..." does not exist`                   | نفس الحل السابق                                                          |
| `database "mecca_bakeries" does not exist`    | `createdb mecca_bakeries`                                                |
| `Cannot find module ... @mecca/shared/dist`   | `pnpm run bootstrap` أو `pnpm --filter @mecca/shared build`              |
| `ECONNREFUSED ... 5432`                       | PostgreSQL متوقف: `brew services start postgresql@16`                    |

### الفحوصات قبل كل دمج

```bash
pnpm typecheck && pnpm lint && pnpm format:check && pnpm --filter @mecca/api test
```

## المهام 4، 7، 8، 10، 11 — الدخول والصلاحيات والتدقيق والمستخدمون ✅

**تم:**

- الدخول بالبريد + رمز من 6 أرقام (صالح 10 دقائق، 5 محاولات، 5 طلبات كل 15 دقيقة)
- الجلسة تبقى بعد تحديث الصفحة، والخروج يُنهيها
- 7 أدوار بصلاحيات افتراضية + صلاحيات خاصة لكل مستخدم (من الخادم)
- لا يمكن تعطيل آخر مدير عام
- كل تعديل يُسجل في سجل التدقيق

**متبقٍ:** زر Google في اللوحة، زر الإنجليزية، شاشة تعديل الدور والصلاحيات الخاصة.

**QA يدوي:**

- [ ] فتح `localhost:3000` بدون دخول يحوّل لصفحة الدخول
- [ ] إدخال بريد المدير → يظهر حقل الرمز → الرمز في نافذة الـ API → يدخل للوحة
- [ ] رمز خاطئ يعطي رسالة خطأ بالعربي؛ بعد 5 محاولات خاطئة يُرفض الرمز
- [ ] بريد غير مسجّل: نفس الرسالة (لا يكشف أن البريد غير موجود) ولا يظهر رمز
- [ ] تحديث الصفحة (Cmd+R) بعد الدخول: يبقى مسجّلاً
- [ ] زر «خروج» يرجع لصفحة الدخول، وتحديث الصفحة لا يعيده للوحة
- [ ] المستخدمون ← «+ مستخدم جديد» بدور «موظف الطلبات» → يظهر في الجدول
- [ ] نفس البريد مرة ثانية → رسالة «البريد مستخدم مسبقاً»
- [ ] الدخول بحساب موظف الطلبات (نافذة خاصة): القائمة لا تعرض «المستخدمون والصلاحيات»
- [ ] من حساب المدير: «تعطيل» الموظف → محاولة دخوله تُرفض
- [ ] لا يظهر زر تعطيل لحسابك أنت

## المهمة 12 — العملاء والفروع ✅

**تم:**

- كود عميل تلقائي `C0001` أو كود يدوي (بدون تكرار)
- «الفرع الرئيسي» يُنشأ تلقائياً بنفس العنوان والهاتف
- كود فرع `C0001-01`، `C0001-02` … ولا يُعاد استخدام الرقم
- بحث بالكود/الاسم/الهاتف، فلترة بالفئة والحالة، صفحات
- فئات العملاء (إضافة، تعطيل)
- إيقاف/تفعيل العميل والفرع (لا يوجد حذف)
- كل تعديل في سجل التدقيق

**متبقٍ:** ربط العميل بالاسم التجاري (المهمة 13)، وحسابات المطاعم للتطبيق (المرحلة 2).

**QA يدوي:**

- [ ] المطاعم ← «الفئات» ← إضافة «مطاعم» و«فنادق»
- [ ] إضافة نفس اسم الفئة مرة ثانية → رسالة خطأ
- [ ] «+ عميل جديد» بدون كود → يأخذ `C0001` وعمود الفروع = 1
- [ ] عميل ثانٍ بكود يدوي `c0100` → يُحفظ `C0100` (أحرف كبيرة)
- [ ] عميل بنفس الكود `C0100` → «الكود مستخدم مسبقاً»
- [ ] كود بأحرف عربية → رسالة خطأ
- [ ] البحث برقم الهاتف أو جزء من الاسم أو الكود يجد العميل
- [ ] فلتر الفئة يعرض عملاء الفئة فقط
- [ ] فتح العميل ← «الفرع الرئيسي» بكود `C0001-01` وعنوان العميل
- [ ] «+ فرع جديد» ← `C0001-02` مع ملاحظة التسليم تظهر تحت اسم الفرع
- [ ] إيقاف الفرع 02 ثم إضافة فرع جديد ← يأخذ `C0001-03` (لا يعيد 02)
- [ ] «تعديل البيانات» ← تغيير الاسم والفئة ← حفظ ← تظهر القيم الجديدة
- [ ] «إيقاف العميل» ← يختفي من فلتر «الفعّالون» ويظهر في «الموقوفون»
- [ ] الدخول كمحاسب: يرى العملاء لكن بدون أزرار إضافة أو تعديل
- [ ] الدخول كسائق: لا تظهر «المطاعم» في القائمة
